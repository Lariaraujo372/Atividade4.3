1. Requisitos funcionais 


1 – Escolher palavra secreta: o sistema deve selecionar aleatoriamente uma palavra de uma lista.
2 – Solicitar letras: o sistema deve permitir que o jogador introduza uma letra de cada vez.
3 – Mostrar a palavra: o sistema deve apresentar as letras acertadas e esconder as restantes.
4 – Validar entradas: o sistema deve aceitar apenas uma letra por tentativa.
5 – Controlar tentativas: o sistema deve retirar uma tentativa quando o jogador errar.
6 – Identificar o resultado: o sistema deve informar se o jogador ganhou ou perdeu.


Requisitos não funcionais 

1 – Facilidade de utilização: o jogo deve apresentar instruções simples e claras.
2 – Desempenho: o jogo deve responder rapidamente às letras introduzidas pelo jogador.
3 – Compatibilidade: o programa deve poder ser executado em computadores com Python instalado.
